# Borrowed Hero in station reference reviews

The station fitting scene combines the unchanged, linked station master with a
local copy of the owner's WIP MPFB Hero. It is a human-scale review fixture,
not final Hero acceptance or gameplay admission. No paid generation was used.

Station geometry retains [the station output terms](STATION_KIT_01.md).
The MPFB/MakeHuman mesh, target data, rig, weights, system eyes/teeth/tongue,
removable sportswear, Mindfront brows/lashes and MargaretToigo skin sources
are CC0 according to the Hero workstream's retained source records. Facial
targets credit Mika Suominen. Tool code licenses do not replace these asset terms.
The source study uses MPFB 2.0.17; its software is not bundled here.

`assets/visual/station-human-fit-inputs.json` retains the borrowed master's
SHA-256, original provenance text, complete source asset license and independent
verification receipt. The authored scale, source geometry/materials and packed
images are retained in the local copy. The Hero source is not rewritten.
